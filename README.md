# Hey, I'm Hasan 👋

I'm an Electrical & Electronic Engineering (EEE) student who loves building practical things with hardware and software.

Right now, my biggest focus is **[Nexus Academy](https://github.com/hasan-circuito/nexus-academy)** — an interactive platform designed to help people learn Python deeply through hands-on practice, without getting stuck in tutorial hell.

---

### What I've built so far:

* **[Nexus Academy](https://github.com/hasan-circuito/nexus-academy)**  
  An in-browser Python learning engine in Bangla. Runs Python completely on the client side (via Pyodide WebAssembly) and has 1,600+ automated tests to keep the curriculum solid.

* **ESP8266 IoT Thief Detector**  
  A physical security device I built using an ESP8266 microcontroller and motion sensors. When someone enters the room, it triggers an alert over Wi-Fi.

* **[Personal App Blocker](https://github.com/hasan-circuito/personal-App-blocker-)**  
  An Android app I put together using Google AI Studio. I built it for myself because I was getting distracted by social media during my study sessions and needed a hard lock on distracting apps.
